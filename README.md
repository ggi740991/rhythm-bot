# 리듬게임 자동 플레이 봇

Python 기반 리듬게임 자동 플레이 봇입니다. 화면을 실시간 캡처하여 노트를 감지하고, 판정선에 도달하면 자동으로 키를 입력합니다.

## 주요 기능

- **HSV 색상 기반 노트 감지** - OpenCV를 사용한 실시간 노트 인식
- **lane별 독립 감지** - 각 레인을 개별적으로 감지
- **롱노트 지원** - 길게 누르기 자동 처리
- **판정 시스템** - Perfect / Great / Good 판정 범위 설정
- **노트/레일 개별 캡처** - 각 노트와 레일을 개별적으로 캡처 영역 설정
- **실시간 미리보기** - 감지 결과를 실시간으로 확인
- **다크모드 GUI** - 눈에 편한 다크 테마
- **설정 저장/로드** - JSON 기반 설정 자동 저장
- **ESC 긴급 종료** - 언제든 즉시 정지

## 설치 방법

### 1. Python 설치
Python 3.8 이상이 필요합니다.

### 2. 패키지 설치
```bash
pip install -r requirements.txt
```

### 3. 실행
```bash
python main.py
```

## exe 파일 빌드

```bash
pyinstaller build.spec
```
빌드된 파일은 `dist/RhythmBot.exe`에 생성됩니다.

## 파일 구조

```
rhythm-bot/
├── main.py              # 메인 실행 파일
├── gui.py               # RhythmBotGUI - tkinter 기반 GUI
├── config_manager.py    # ConfigManager - JSON 설정 관리

├── requirements.txt     # 필요 패키지 목록
├── build.spec           # PyInstaller 빌드 설정
└── README.md            # 이 문서
```

## 사용 방법

1. 프로그램을 실행합니다.
2. **캡처 영역 설정**: 게임 화면의 노트가 떨어지는 영역을 설정합니다.
   - X, Y, 너비, 높이를 직접 입력하거나 "화면에서 영역 선택" 버튼을 사용합니다.
3. **레인 설정**: 레인 개수와 각 레인의 키를 설정합니다.
4. **HSV 조정**: 노트의 색상에 맞게 HSV 범위를 조정합니다.
   - 디버그 모드를 켜면 감지 결과를 실시간으로 확인할 수 있습니다.
5. **판정선 위치**: 판정선의 위치를 슬라이더로 조정합니다.
6. **시작 버튼**을 클릭하면 자동 플레이가 시작됩니다.

### 노트/레일 개별 캡처

각 레인별로 독립적인 캡처 영역을 설정할 수 있습니다:
- **노트 캡처 영역**: 특정 레인의 노트만 감지할 영역
- **레일 캡처 영역**: 특정 레인 전체를 감지할 영역

이를 통해 각 레인을 정밀하게 설정할 수 있습니다.

## 주요 설정

| 설정 | 설명 |
|------|------|
| 캡처 영역 | 게임 화면에서 노트가 떨어지는 영역 |
| 레인 개수 | 게임의 키(레인) 수 |
| 키 바인딩 | 각 레인에 매핑되는 키 |
| HSV 범위 | 노트 색상 감지 범위 |
| 판정선 위치 | 키를 입력할 위치 (0.0~1.0) |
| 판정 범위 | Perfect/Great/Good 판정 픽셀 범위 |
| 입력 딜레이 | 키 입력 전 대기 시간 (ms) |
| Debounce | 중복 입력 방지 시간 (ms) |

## 단축키
